Collaborative Editor

Multi-user map editing applications for team-based geographic data management.

Characteristics

  • Multiple people working on the same dataset
  • Track changes, history, and rollback
  • Manage concurrent edits gracefully
  • Different permissions for different users
  • Who changed what and when
  • Review and approval workflows
  • See others' changes (optional)
  • Communicate about features
