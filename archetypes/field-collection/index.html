Field Collection

Mobile data gathering applications for field workers.

Characteristics

  • Designed primarily for phones and tablets
  • Leverage device location for placement accuracy
  • Must work in areas with poor connectivity
  • Structured data entry with validation
  • Often includes photos attached to features
  • Handle intermittent connectivity gracefully
  • Efficient use of GPS and network
  • Large buttons, easy gestures
