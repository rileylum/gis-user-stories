Public Portal

Read-only maps for public consumption, emphasizing discoverability, performance, and accessibility.

Characteristics

  • Users consume information, not create it
  • Must serve all users including those with disabilities
  • Fast loading for casual visitors
  • Many users on mobile devices
  • Shareable, indexable content
  • No login required for core functionality
